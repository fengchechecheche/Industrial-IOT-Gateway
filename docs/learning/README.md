## 阅读边界

- 教程中的“计划接口”不等于已经实现的代码；
- 每份教程明确区分当前能力、后续工作和未验证范围；
- MQTT 软件测试不能证明 TLS、生产认证或真实 RS485；
- PTY 测试不能代替硬件电气层证据；
- 进一步学习资料优先引用协议组织、项目和库的官方文档。
