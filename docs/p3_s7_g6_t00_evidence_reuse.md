## 1. 准入结论

P3-S7-G6-T00 按“只验收新增对象、复用项目五冻结证据”的原则完成差异化准入。新增的两只

## 3. TAS 官方资料与新增对象

两只设备标签均确认型号为 `TAS-WS-R00020`，人工区分为 TAS-A 和 TAS-B。官方资料冻结：

```text
TAS-WS-R0X020 扁卡轨式温湿度传感器说明书 V1.6
扁卡轨式传感器产品规格书 V1.0.4
塔石传感器寄存器定义说明 V1.6
```

冻结合同：

| 项目 | 合同 |
|---|---|
| 端子 | 1=A+、2=B-、3=DC+、4=DC-、5=NC |
| 通信参考 | 设备无独立 RS485 GND；`DC-` 不作为通信参考 |
| 默认通信 | 地址 1、9600 8N1 |
| 目标通信 | TAS-A 地址 1、TAS-B 地址 2、19200 8E1 |
| 测量寄存器 | `0x0000～0x0001`，湿度和温度 |
| 串口设置 | `0x0300`，写入 FLASH，重启生效 |
| 地址设置 | `0x0320`，写入 FLASH，立即生效 |

两只设备没有可用于区分个体的有效 SN：寄存器返回 16 个字符 `0`，因此身份依靠标签照片和人工
标记，不把该字段写成唯一序列号。

## 4. 供电、参考与终端边界

- 两只 TAS 使用同一合格 12 V 低压直流电源的独立支路；
- TAS 的可拆卸端子同时包含 DC+/DC-/A/B，可用于低压侧整体支路断开；
- TAS 只连接 A/B，不把 DC- 推测为通信参考；
- USB-RS485 与 Shield 均确认具有 120 Ω 终端，并分别位于最终总线两端；
- TAS-A、TAS-B 位于中间，不增加终端；
- 当前没有万用表，120 Ω 来自设备资料/选型确认，不能声明为实测阻值；
- 桌面短线台架不以精确主干和支线长度作为准入门，但不能外推到长线工业布线。

最终拓扑：

```text
USB-RS485〔首端 120 Ω〕
  ── TAS-A〔地址 1〕
  ── TAS-B〔地址 2〕
  ── Waveshare Shield + STM32〔地址 4，末端 120 Ω〕
```
