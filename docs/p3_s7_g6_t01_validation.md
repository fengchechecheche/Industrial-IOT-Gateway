## 2. 单机只读验收

初次验收时每次只连接一只出厂地址 1 的 TAS，避免同地址冲突。两只设备均确认：

- 型号 `TAS-WS-R00020`；
- 默认地址 1、9600 8N1；
- 固件版本 `WSQY-R0002000-C-V1.4.5`；
- `0x0000～0x0001` 可读取湿度和温度；
- 响应功能码、字节数和 CRC16 正确；
- 10 分钟各完成 1200/1200 次读取，无超时、CRC 错误、异常响应或数值越界；
- 低压侧断电不少于 5 秒后，首次正向请求即可重新读取。

| 设备 | 连续读取 | 超时 | CRC/异常 | 断电恢复 | 结果 |
|---|---:|---:|---:|---|---|
| TAS-A | 1200/1200 | 0 | 0 | PASS | PASS |
| TAS-B | 1200/1200 | 0 | 0 | PASS | PASS |

温湿度数值只用于检查协议缩放、合理范围和持续变化，不作为计量精度证据。

## 3. TAS-A 配置与持久化

在用户审核通过的操作单边界内，只写入串口配置寄存器 `0x0300`，不执行其他配置写入或盲目重试。
设备返回正确的功能码 16 确认帧，FLASH 读回为 `00 4B 00 18`，对应 19200 8E1。

低压断电重启后：

| 检查 | 结果 |
|---|---|
| 地址 1 / 19200 8E1 温湿度读取 | PASS |
| 串口配置读回 | 19200 8E1 |
| 地址读回 | 1 |
| 旧 9600 8N1 连续两次探测 | 无响应 |
| 正向响应 CRC | 全部正确 |

最终冻结：`TAS-A = address 1 / 19200 8E1`。

## 4. TAS-B 地址迁移、串口配置与持久化

TAS-B 单独接入时，先使用功能码 06 将 `0x0320` 从地址 1 迁移到地址 2，再使用功能码 16 将
`0x0300` 写为 19200 8E1。每个写请求只发送一次，回显/确认帧和 CRC 均正确。

写入后、重启前已经确认地址 2 和目标串口写入 FLASH。首次执行器曾把正确 CRC `B9 2F` 与错误的
硬编码期望 `89 1B` 比较而返回 1；写入已经成功，因此没有重发。随后只用功能码 03 复核并保留了
该脚本缺陷记录，不能把它写成设备或链路失败。

低压断电重启后：

| 检查 | 结果 |
|---|---|
| 地址 2 / 19200 8E1 温湿度读取 | PASS |
| 串口配置读回 | 19200 8E1 |
| 地址读回 | 2 |
| 地址 1/9600、地址 2/9600、地址 1/19200 | 各连续两次无正常响应 |
| 正向响应 CRC | 全部正确 |

最终冻结：`TAS-B = address 2 / 19200 8E1`。

## 6. 能力边界

本工作块证明两只 TAS 的单机通信和必要配置能够持久保存。它不证明双从站/三从站并发、故障隔离、
systemd 恢复或八小时稳定性；这些能力分别由 T02、T03 和 T04 证明。设备个体依靠人工标签区分，
不能把返回全零的 SN 字段当作唯一身份。
